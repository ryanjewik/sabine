figma prototype link: https://www.figma.com/design/FbJGgsLIaidxzPkjHDsrwv/valorant-chatbot-app?node-id=0-1&m=de

1. cd into "flask-server"
2. run ".\venv\Scripts\Activate.ps1"
3. run "python server.py"
4. cd into "client"
5. run "npm start"
